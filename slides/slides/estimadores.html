06 · Estimadores

De dentro para fora, estágio por estágio

Estimativa pontual (Horvitz–Thompson)

T̂ₖ = Mₖ · ȳₖ

Ŷⱼₕ = (Nⱼₕ / nⱼₕ) · Σₖ T̂ₖ

Ŷ = (B / b) · Σⱼ Σₕ Ŷⱼₕ = Σ w·y

R̂ = Σ w·yᵢ/fᵢ ÷ Σ w/fᵢ (estimador razão)

P̂ usa o mesmo estimador com a indicadora dᵢ.

Variância por estágios (com FCPF)

V̂(Ŷ) = B²(1 − b/B) s²ᵤ/b + (B/b) Σⱼ V̂(Ŷⱼ)

V̂(Ŷⱼ) = Σₕ [ Nⱼₕ²(1 − nⱼₕ/Nⱼₕ) s²₁ⱼₕ/nⱼₕ + (Nⱼₕ/nⱼₕ) Σₖ Mₖ²(1 − mₖ/Mₖ) s²₂ₖ/mₖ ]

Linearização: zᵢ = (yᵢ − R̂)/fᵢ → V̂(R̂) ≈ V̂(Ẑ) / N̂²

IC: R̂ ± t₃ · EP, com t₃ = 3,182 (gl = b − 1). Para P: IC logit.

Estimadores (≈ 60 s). O total é estimado de dentro para fora. A média é uma razão porque o número de jogadores também é desconhecido. A variância soma um termo por estágio, cada um com sua correção para população finita (Cochran cap. 11; Thompson eq. 13.6–13.8). A variância da razão vem da linearização de Taylor. Com só 4 blocos, os graus de liberdade vêm dos blocos: t com 3 gl. Para proporções perto de 1, o IC de Wald passa de 1, por isso o IC logit.
